# Example data

| File | Description |
|------|-------------|
| `field_trial.csv` | Small plant breeding trial: 6 genotypes x 3 reps with a block factor and one missing plot (`NA`). `rep` and `block` are numeric codes, so pass `--factor rep` (CLI) or call `as_factor("rep")` (Python) to treat them as categorical. |
| `mrode_pedigree.csv` | Pedigree of Mrode (2005) *Linear Models for the Prediction of Animal Breeding Values*, Example 3.1 (8 animals, `0` = unknown parent). |
| `mrode_records.csv` | Pre-weaning gain records for the five animals with phenotypes in the same example. With only five records the REML estimate of the residual variance is on the boundary (zero), so this set is meant for the fixed-variance validation and `ainverse`, not as a REML demo. |
| `animal_pedigree.csv` | Simulated three-generation pedigree: 12 founders, 24 first-generation and 27 second-generation animals (63 in total). |
| `animal_records.csv` | Simulated weights for the 51 non-founder animals (sex effect male +4, sigma²_a = 20, sigma²_e = 40, seed 20240912; see the generator note below). Use it for the animal-model REML examples. |

```bash
# Plant trial: yield = mu + rep (fixed) + genotype (random)
openblup fit --data examples/field_trial.csv --response yield \
    --fixed "mu + rep" --factor rep --random genotype --blups blups.csv

# Animal model with pedigree A-inverse (all 63 animals get a breeding value)
openblup fit --data examples/animal_records.csv --response weight \
    --fixed sex --random animal --pedigree examples/animal_pedigree.csv

# Inspect the A-inverse and inbreeding coefficients
openblup ainverse --pedigree examples/mrode_pedigree.csv --inbreeding
```

With the variance components fixed at Mrode's values (sigma²_a = 20, sigma²_e = 40) the
animal model reproduces the textbook solutions exactly; see
`crates/core/tests/pedigree_blup_test.rs`.

The simulated animal data were generated by sampling founder breeding values from
N(0, sigma²_a), offspring breeding values as the parent average plus Mendelian sampling
with variance sigma²_a (0.5 - 0.25 (F_s + F_d)), and residuals from N(0, sigma²_e). With
51 records the REML estimates are, as expected, noisy (sigma²_a ≈ 37, sigma²_e ≈ 17), but
AI-REML and EM-REML agree to six digits.
